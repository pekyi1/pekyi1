### 🔄 About Me:

Hi, I'm Fred Pekyi, a QA Engineer passionate about building reliable, well-tested software. I combine manual and automated testing to catch defects early, and I write automation in Java and JavaScript/TypeScript across UI and API layers.

I've worked across assessment management, service ticketing, and game management platforms — designing regression suites, managing test artifacts in Jira/Xray, and building AI agent tooling that automates test-case authoring end-to-end. I'm always eager to learn, collaborate, and use technology to build quality into every stage of delivery, not just catch bugs at the end.
